## Adding fixed-duration tasks

Adds a task that has a fixed estimated duration but no scheduled start, end, or deadline.

Format: `duration <description> /for <positive-whole-number><unit>`

Supported units are `h` for hours and `m` for minutes. For example:

```text
duration read the sales report /for 2h
```

The task is shown as:

```text
[F][ ] read the sales report (for: 2 hours)
```

The duration must be a positive whole number followed by `h` or `m`. For example,
`duration read the sales report /for 1.5h` is rejected.
